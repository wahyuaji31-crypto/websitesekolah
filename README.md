# Website Sekolah SMA Negeri 1 Harapan Bangsa

Website profil dan sistem informasi resmi SMA Negeri 1 Harapan Bangsa yang modern, elegan, cepat, dan sepenuhnya responsif (Desktop, Tablet, Mobile).

## 🌟 Fitur Utama

- 🏠 **Beranda (Home)**: Hero slider interaktif, statistik sekolah animasi, sambutan Kepala Sekolah, program peminatan Kurikulum Merdeka, berita terkini, dan testimoni alumni.
- 🏫 **Profil Sekolah**: Sejarah, Visi & Misi 2030, struktur pimpinan, dewan guru & tenaga pendidik, serta sarana & prasarana kampus.
- 📚 **Akademik & Kesiswaan**: Struktur Kurikulum Merdeka, kalender akademik tahunan, 6 Dimensi Profil Pelajar Pancasila, dan direktori ekstrakurikuler.
- 📰 **Berita & Pengumuman**: Filter artikel berdasarkan kategori (*Prestasi, Pengumuman, Kesiswaan, Akademik*), pencarian cepat, dan popup modal pembaca berita.
- 📸 **Galeri Multimedia**: Dokumentasi foto kegiatan dengan filter kategori dan Lightbox zoom interaktif.
- 📝 **PPDB Online 2026/2027**: 
  - Alur dan syarat berkas pendaftaran.
  - Formulir pendaftaran calon siswa bertahap (Multi-Step 3 Langkah).
  - Cetak otomatis **Kartu Bukti Pendaftaran (PDF/Print View)** lengkap dengan Nomor Registrasi.
  - Tracking status pendaftaran secara realtime.
- 📞 **Kontak & Layanan Aspirasi**: Form pengaduan/pesan ke Tata Usaha, embed peta lokasi Google Maps interaktif, dan FAQ akordeon.

## 🚀 Teknologi yang Digunakan

- **HTML5 & CSS3**
- **Tailwind CSS** (Modern utility-first CSS framework)
- **Lucide Icons** (Clean & modern vector icons)
- **Vanilla JavaScript (ES6+)**
- **Google Fonts** (Plus Jakarta Sans)

## 💻 Cara Menjalankan

Cukup clone repository ini dan buka file `index.html` langsung di browser Anda:

```bash
# Clone repository
git clone https://github.com/wahyuaji31-crypto/websitesekolah.git

# Masuk ke direktori
cd websitesekolah

# Buka index.html di browser Anda
```
